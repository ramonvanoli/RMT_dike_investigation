# MATLAB Scripts

The MATLAB scripts in this folder are based on the [`mtcode`](https://github.com/darcycordell/mtcode) repository by Darcy Cordell.

Parts of the original `mtcode` code were adapted for use with radiomagnetotelluric (RMT) data. In particular, the code was modified to support the smaller grid sizes required for RMT applications, including grid sizes below 1 m.
